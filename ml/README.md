# Machine Learning

Contains reproducible data preparation, demand forecasting, and inventory risk models.

Planned modules:
- preprocessing: validation, cleaning, feature engineering
- forecasting: baseline and machine-learning demand models
- risk: stockout, overstock, and slow-moving inventory scoring
- evaluation: chronological validation and model metrics

Start with transparent baselines. Use time-based splits to avoid leakage. Track dataset versions and report forecast metrics by product/category as well as in aggregate.
